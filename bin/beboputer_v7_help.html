Beboputer Virtual Computer — Help

The Beboputer Virtual Computer is a software emulator of the DIY Calculator CPU described in How Computers Do Math by Clive "Max" Maxfield & Alvin Brown. It provides a full 64 KB RAM space, an assembler, memory inspection tools, and several hardware peripherals accessible through memory-mapped I/O.

Overview

When the application starts, three windows open automatically:

  • Calculator — top-left of the screen. Its On/Off button controls power to the Terminal and the Workbench.
  • Memory Walker — left panel. Browse and edit RAM, single-step the CPU, set breakpoints.
  • Message Display — right panel. Diagnostic log showing every instruction executed and all system events.

All other panels are available but hidden at startup. Open them from the Display or Tools menus as needed.

File Menu

A Project is the whole session — which panels are open and where, the calculator's power state, the simulated clock speed, and the RAM contents — saved as one .prj file. Load RAM / Save RAM are a separate, narrower pair that only ever touch the raw RAM image as a .rom/.ram binary, with no session/layout information.
ItemAction
New Project…Clears all 64 KB of RAM, resets the CPU, and closes every panel back to the default startup layout. Asks for confirmation first.
Open Project…Loads a .prj session file: panel layout, calculator power state, clock speed, and the full RAM image.
Save Project…Saves the current session to its .prj file. Prompts for a filename the first time (same as Save Project As), then reuses it.
Save Project As…Same as Save Project — always prompts for a new filename.
Load RAM…Loads a .rom or .ram binary straight into RAM (no panel/session state). .rom files load at $0000; .ram files (and anything else) load at $4000. A file exactly 64 KB is treated as a full RAM image loaded at $0000.
Save RAM…Saves the entire 64 KB RAM image as a raw .rom file — RAM contents only, no session/layout information.
Purge RAM…Zeros every byte of RAM without resetting the CPU. The Memory Walker updates immediately. Asks for confirmation.
ExitCloses the application.

Toolbar

A single always-visible toolbar sits below the menu bar.
ButtonAction

Only takes effect while the calculator is switched ON; if it's off, the button logs "Interrupt ignored — calculator is off." and does nothing.

Memory Walker

Browse any address in 64 KB RAM, edit bytes directly, single-step the CPU, and set/clear breakpoints — all in one panel.

Message Display

An always-on diagnostic log that records every emulator event.

Each entry includes the instruction name and addressing mode, the post-execution register snapshot (ACC, PC, SP, IX), and the flag state (I, O, N, Z, C). System events also appear here: file loads, clock changes, resets, HALTs, and breakpoint hits.

Disassembler

Displays a live disassembly of RAM from any start address, updated automatically as the CPU steps.

The Disassembler reads the current RAM contents and decodes bytes into human-readable mnemonics. It tracks the Program Counter and scrolls to keep the active instruction visible. Use it alongside the Memory Walker to understand what a loaded program is doing at each address.

On-Screen Keyboard

Sends keystrokes to the CPU as ASCII bytes via memory-mapped port $F011.

Workbench 1

A hardware simulation panel with two 8-bit toggle switch banks, an 8-bit LED bar, and three 7-segment displays. Requires the calculator to be switched ON.

Inputs

ComponentPortDescription
8-Bit Switch Bank 1 $F000 Eight toggle switches. Flip down (green) = ON / logic 1; up (red) = OFF / logic 0. Read the combined byte with LDA [$F000].
8-Bit Switch Bank 2 $F001 Second bank of eight toggle switches, same behaviour as Bank 1. Read with LDA [$F001].

Outputs

ComponentPortDescription
7-Seg Undecoded $F021 Raw segment-pattern display. Each of bits 6..0 lights one segment (a–g) directly. Write any value 0–127. STA [$F021]
8-Bit LED Bar $F022 Eight LEDs. Bit 0 = rightmost LED. Bright green = ON, dull green = OFF. STA [$F022]
7-Seg Decoded (single) $F023 Decodes the low nibble of the written byte as a hex digit 0–F using bitmap images. STA [$F023]
Dual 7-Seg Decoded $F024 Two side-by-side decoded digits. High nibble = left digit, low nibble = right digit. Write a full byte to show both simultaneously. STA [$F024]

Power Gating

The entire Workbench is disabled when the Calculator is off. Switch interactions and CPU write hooks are silently ignored. On power-on, displays update to reflect the current RAM values.

Example Program

SW1:     .EQU  $F000          # 8-bit switch bank 1
LED8:    .EQU  $F022          # 8-bit LED bar
SEG7DD:  .EQU  $F024          # dual 7-seg decoded

         .ORG  $4000

LOOP:    LDA   [SW1]          # read switch byte
         STA   [LED8]         # mirror to LED bar
         STA   [SEG7DD]       # hi nibble = left digit, lo = right
         JMP   [LOOP]         # repeat forever

Peripherals & I/O Map

All hardware peripherals communicate with the CPU through memory-mapped addresses in the $F000–$F0FF range. Use LDA [addr] to read an input port and STA [addr] to write an output port.

Workbench 1 — Inputs

PeripheralAddressDirDescription
8-Bit Switch Bank 1 $F000 IN Read the 8 toggle switches as a byte. Bit = 1 when switch is DOWN (ON/green). Example: LDA [$F000]
8-Bit Switch Bank 2 $F001 IN Second bank of 8 toggle switches. Same bit convention as Bank 1. Example: LDA [$F001]

Workbench 1 — Outputs

PeripheralAddressDirDescription
7-Seg Undecoded $F021 OUT Raw segment control. Bits 6..0 map directly to segments a–g. Write values 0–127. Example: STA [$F021]
8-Bit LED Bar $F022 OUT Controls 8 LEDs. Bit 0 = rightmost LED. 1 = bright green, 0 = dull green. Example: STA [$F022]
7-Seg Decoded (single) $F023 OUT Low nibble of the written byte is decoded as a hex digit 0–F. Example: STA [$F023]
Dual 7-Seg Decoded $F024 OUT High nibble drives the left digit; low nibble drives the right digit. Both update from a single byte write. Example: STA [$F024]

Keyboard

PeripheralAddressDirDescription
On-Screen Keyboard $F011 IN Keyboard writes ASCII key values here. CPU reads with LDA [$F011]. Value is $00 when no key is pressed ($FF = idle sentinel at reset).

Terminal

PeripheralAddressDirDescription
Terminal Screen $F028 OUT Write one ASCII byte to print it on the Terminal screen. Printable: 32–126. $0A = newline. Other values ignored. Example: STA [$F028]

Calculator

PeripheralAddressDirDescription
Calculator Display $F031 OUT Write one ASCII byte to append it to the Calculator's scrolling display. Write $1B (ESC) to clear the display. Example: STA [$F031]
Calculator LED Strip $F032 OUT Write a byte to light up to 6 LEDs. Bits 5..0 = LEDs left to right. 1 = bright red, 0 = dark red. Example: STA [$F032]

CPU Flags Reference

FlagBitSet byUsed by
C — Carry0ADD, ADDC, SUB, SUBC, SHL, SHR, ROLC, RORC, CMPA (set if ACC > operand)JC, JNC, ADDC, SUBC
Z — Zero1Any arithmetic/logic instruction that produces zeroJZ, JNZ

CMPA carry note: Unlike many CPUs, the Carry flag is set when ACC > operand (not <). To test if a nibble is a hex letter (A–F): CMPA $09 then JC [letter] — jumps if ACC > 9.
